# AI Hub Memoria — extensao Chrome / Edge / Brave

Extensao Manifest V3 original. Serve Qwen, DeepSeek, GLM/Z.ai e Mistral com a mesma biblioteca de memorias.

## Instalar

1. Chrome / Edge / Brave → `chrome://extensions/`
2. Activar Modo de programador
3. Carregar sem compactacao → pasta `extension/`
4. Abrir os chats oficiais ja com login
5. Canto inferior direito: dock AI Hub

Com o servidor `local/server.py` a correr, Chat → DOCX/PDF/XLSX grava em `local/exports/`.
